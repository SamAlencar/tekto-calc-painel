# Painel Tekto

Painel público de acompanhamento dos projetos da **Tekto** (Tekto Calc, Tekto Docs, Tekto Model).

Os repositórios dos projetos são privados. Este repositório contém apenas a página estática e o arquivo `data.json` com metadados de progresso (tarefas do backlog, entregas mescladas, normas e dúvidas em aberto), gerado por `gerar_dados.py`.

Página: https://samalencar.github.io/tekto-calc-painel/
