# Tekto Calc · Painel de progresso

Painel público de acompanhamento do projeto **Tekto Calc**, um acervo de rotinas de cálculo de engenharia segundo as normas ABNT NBR.

O código de cálculo é privado. Este repositório contém apenas a página estática e o arquivo `data.json` com metadados de progresso (tarefas do backlog, entregas mescladas, normas e dúvidas em aberto), gerado por `gerar_dados.py`.

Página: https://samalencar.github.io/tekto-calc-painel/
